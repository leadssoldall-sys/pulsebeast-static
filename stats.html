📡 Webhook Setup

To enable real-time stats:

  1. Go to Square Dashboard → Developer → Webhooks
  2. Add endpoint: https://your-domain.vercel.app/api/webhook
  3. Subscribe to: payment.created and payment.updated
  4. Copy Signature Key and add to Vercel env: SQUARE_WEBHOOK_SIGNATURE_KEY
