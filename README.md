# PulseBeast – AI Roofing Beast

Static HTML version of PulseBeast dashboard with all features:
- MiniGrok AI chat
- Phone Bot (Twilio/LMN)
- E-Book Writer
- Video Studio
- Script Templates
- Thumbnail Maker
- Traffic Tools
- Leads Funnel
- Contact Form
- Calendar/Bookings

## Deploy to Vercel

1. Push this repo to GitHub
2. Import on Vercel
3. Deploy (no build needed)

Live at: https://pulsebeast-static.vercel.app
